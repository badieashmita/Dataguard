# Dataguard
DataGuard- Real time email breach checker with dark web scanning. Firebase auth &amp; live threat intelligence. .

🎯 What is DataGuard?
A privacy tool that lets you check if your 
personal data has been leaked, where it lives 
online, and how to delete it from 10+ platforms.

---

## ⚡ Core Features
- 🔍 Email breach detection via HIBP API
- 🌑 Dark web scan results
- 🗑️ Step-by-step deletion guides (Google, Meta + 8 more)
- 👤 Firebase Auth — personal breach dashboard
- 🔐 Zero sensitive data stored or logged

---

## 🛠️ Built With
- HTML + CSS + JavaScript (Frontend)
- Firebase Auth + Firestore (Users & Data)
- Firebase Hosting (Deployment)
- HaveIBeenPwned API (Breach detection)
- Figma (Wireframes)
